### Engineering Projects & Hackathon Implementations

#### [DisasterOS: High-Performance Extreme Weather Dashboard](https://disaster-os.pages.dev)
* **Context**: Developed during the Runspace Innovation Challenge hosted by the Taiwan Space Agency (TASA).
* **Architecture**: React, Node.js, HTML5 Canvas.
* **Engineering Impact**: Identified severe memory leaks when rendering tens of thousands of GeoJSON data points via standard SVG maps. Rewrote the underlying rendering engine to utilize HTML5 Canvas and implemented polygon simplification algorithms. This architectural shift reduced the frontend rendering load by 70%, enabling real-time monitoring of disaster zones without browser crashes.

#### [BentoFlow: ESG Green Logistics Prediction System](https://bentoflow-3l4.pages.dev)
* **Context**: Developed for the Taiwan Railways Data Hackathon.
* **Architecture**: Python, Data Normalization, Predictive Modeling.
* **Engineering Impact**: Engineered an algorithmic solution to address the massive food waste generated by unsold bento boxes across the national railway network. The system processes historical sales data to generate highly accurate daily supply predictions for individual stations, demonstrating clear commercial viability and ESG impact.

#### Low-Cost Edge AI Respiration Monitor
* **Context**: Independent Hardware R&D targeting the Macronix Science Award.
* **Architecture**: ESP32 Microcontroller, I2S Digital Microphone, Python Asynchronous Server, iOS App (Capacitor).
* **Engineering Impact**: Built an end-to-end IoT medical device to detect sleep apnea. Handled all hardware layers, including custom circuit design and cold solder joint debugging, and integrated the edge computing analysis with a real-time iOS push notification system to alert caretakers.

#### [Quantum Approximate Optimization Algorithm (QAOA) Implementation](https://github.com/zhuang768)
* **Context**: NTU x IBM Quantum Computing Hackathon.
* **Architecture**: IBM Qiskit, Graph Theory.
* **Engineering Impact**: Utilized IBM's real quantum hardware APIs to solve complex bipartite graph cutting problems. Generated extensive data visualizations to benchmark the operational differences between quantum simulators and physical quantum computers.

#### Cross-Department AI Dispatch Architecture
* **NexusCity (VoltHacks)**: Automated emergency dispatch platform utilizing Google Gemini API and Twilio SMS integration.
* **EcoPredict (Reverie Hacks)**: Designed an LLM-driven agent architecture specifically for social workers to automate disaster relief task assignments.
